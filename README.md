# SIP STUDIO

时尚吸管保温杯品牌概念主页。三种配色：燕麦拿铁、电光蓝、落日珊瑚。

## 本地运行

需要 Node.js 18+ 与 Python 3，不需要安装第三方依赖。

```sh
npm run build
npm run preview
```

访问 http://127.0.0.1:4318 。停止预览可按 Ctrl+C。

## 部署

构建命令为 `npm run build`，输出目录为 `dist`。可部署到支持静态文件的服务。Vercel 配置已放在 `vercel.json`。

## 功能与范围

- 响应式品牌主页、三配色产品展示、配色切换、产品详情弹窗。
- 购物袋支持添加、增减、移除、清空，保存在当前浏览器 localStorage。
- FAQ、使用保养指南、键盘操作与减少动态效果设置。
- 页头源码获取组件，保留提供者原始二维码及真实小红书主页。

这是虚构品牌设计概念，图片由 AI 生成。价格、容量与产品设计用于展示，不代表真实商品承诺。没有支付、订单、库存、配送、会员或后台服务。没有保温性能测试数据，不宣称已验证保温时长或密封性能。无需环境变量，也不收集用户表单数据。localStorage 不可用时购物袋退化为当前页面内存保存。

## 编辑

`index.html` 为页面结构，`styles.css` 为样式，`app.js` 为交互与产品数据，`public/assets/` 为原创生成视觉。`public/source-access/` 为工作区提供的共用源码入口及原始名片。

所有运行资源随源码提供；Google Fonts 是可选字体样式，无法加载时使用系统字体。
